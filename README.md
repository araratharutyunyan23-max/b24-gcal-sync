# b24-gcal-sync

A personal, single-user tool that copies the owner's work meetings from a corporate
Bitrix24 calendar into a dedicated calendar in the owner's own Google Calendar.

- One-way: Bitrix24 → Google Calendar.
- Writes only to a calendar the tool creates itself (`calendar.app.created` scope);
  it cannot read or change any other calendar.
- Runs only on the owner's computer. No servers, no third parties.
