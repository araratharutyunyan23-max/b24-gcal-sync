Privacy policy

Effective date: 26 October 2026. Applies to the application b24-gcal-sync.

Who uses the application

The application is a personal tool used by a single person, the owner of this repository. It is not offered to the public and has no other users.

What data it accesses

Google: only one calendar that the application creates itself, through the scope https://www.googleapis.com/auth/calendar.app.created. The application cannot see or change any other calendar or any other data in the Google account.

Into that calendar it writes the owner's own work meetings taken from the owner's Bitrix24 calendar: title, start and end time, location or meeting link, description and the names of participants.

Where data is stored

The OAuth tokens and a small synchronisation state file are stored only on the owner's own computer, readable only by the owner. The application has no server and no database of its own.

Sharing

No data is sold, shared, or transferred to any third party. No analytics, advertising or tracking is used. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Events stay in the Google calendar until the owner deletes them or the calendar. Access can be revoked at any time at myaccount.google.com/permissions, after which the application can no longer write anything.
